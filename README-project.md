# Qwen3.5-2B → MoE-0.4B

پروژهٔ پژوهشی برای ساخت مدل زبانی متن‌محور، فارسی‌فهم و مناسب اجرای آفلاین روی اندروید با بودجهٔ محاسباتی محدود.

## وضعیت

**مرحلهٔ صفر: بررسی پیکربندی مدل مبدأ.** هنوز مدل MoE ساخته یا آموزش داده نشده است. این مخزن فعلاً ابزارهای ممیزی و آزمایش اولیه را نگه می‌دارد.

## اصول پروژه

- استفاده از منابع رایگان؛ هیچ GPU یا Job پولی بدون تأیید صریح اجرا نمی‌شود.
- اندازه‌گیری جداگانهٔ پارامترهای کل، پارامترهای فعال و هزینهٔ محاسباتی مسیر تولید توکن.
- شروع با ممیزی پیکربندی و آزمایش کوچک؛ نه تبدیل یک‌بارهٔ تمام ۲۴ لایه.
- ثبت نتایج قابل‌بازتولید، نسخهٔ کتابخانه‌ها و شناسهٔ دقیق مدل.
- ارزیابی فارسی، ریاضی، منطق، پیروی از دستور، RAM، سرعت و امکان اجرای موبایل.

## نکتهٔ معماری

مدل مبدأ Qwen/Qwen3.5-2B از معماری Qwen3_5ForConditionalGeneration استفاده می‌کند و پیکربندی آن شامل ۲۴ لایهٔ متنی، hidden size برابر ۲۰۴۸، intermediate size برابر ۶۱۴۴، واژگان ۲۴۸٬۳۲۰ و لایه‌های ترکیبی Linear Attention / Full Attention است. چون embedding مشترک به‌تنهایی حدود ۵۰۸.۶ میلیون پارامتر دارد، سقف ۰.۴B برای کل مسیر تولید توکن با حفظ این ابعاد سازگار نیست؛ باید مسیر دانش‌آموز کوچک‌تر هم بررسی شود.

## شروع

1. Notebook با مسیر notebooks/01_model_audit.ipynb را در Google Colab یا Kaggle باز کنید.
2. سلول‌های بررسی پیکربندی را اجرا کنید؛ این مرحله برای دانلود کل وزن‌های چندگیگابایتی نیاز ندارد.
3. برای بارگذاری کامل مدل، پیش از اجرا فضای RAM/VRAM و دسترسی رایگان محیط را بررسی کنید.
4. خروجی JSON ممیزی را ذخیره کنید و سپس دربارهٔ معماری نمونهٔ MoE تصمیم بگیرید.

## هزینه

این مخزن هیچ محاسبهٔ پولی را خودکار اجرا نمی‌کند. سهمیهٔ رایگان Colab/Kaggle ممکن است تغییر کند و تضمین GPU رایگان وجود ندارد.
