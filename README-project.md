# Qwen3.5-2B → Mobile MoE (~0.51B active)

پروژهٔ پژوهشی برای ساخت مدل زبانی متن‌محور، فارسی‌فهم و مناسب اجرای آفلاین روی اندروید با CPU و حافظهٔ محدود.

## هدف فعلی

هدف معماری به‌روزرسانی شده است: **حدود ۵۰۸٫۶ میلیون پارامتر فعال در هر توکن**؛ تعداد کل پارامترهای مدل می‌تواند بیشتر باشد. طرح محاسباتی اولیه با hidden size=1,024، ۲۴ لایه، ۸ متخصص و top-2 حدود 506.6M پارامتر فعال و حدود 1.073B پارامتر یکتا برآورد می‌کند.

جزئیات، فرمول‌ها، فرض‌ها و محدودیت‌ها در [بودجهٔ معماری](docs/ARCHITECTURE_BUDGET.md) ثبت شده است.

## وضعیت واقعی

- اتصال GitHub به Hugging Face و انتقال فایل‌های پروژه آزمایش شده است.
- ممیزی config مدل مرجع انجام شده است؛ وزن‌های کامل مدل هنوز دانلود یا شمارش مستقیم نشده‌اند.
- معماری مقصد فعلاً برآورد محاسباتی است؛ هنوز مدل MoE ساخته یا آموزش داده نشده است.
- هنوز سازگاری runtime اندروید، کیفیت فارسی، سرعت و RAM روی گوشی آزموده نشده‌اند.

## مدل معلم و مرجع

- مرجع: `Qwen/Qwen3.5-2B`.
- config مرجع: ۲۴ لایهٔ متنی، hidden size برابر ۲۰۴۸، intermediate size برابر ۶۱۴۴، واژگان ۲۴۸۳۲۰ و attention ترکیبی linear/full.
- کوچک‌سازی hidden size به ۱۰۲۴ یعنی انتقال مستقیم همهٔ وزن‌ها ممکن نیست؛ لازم است تبدیل محدود وزن‌ها و/یا تقطیر دانش ارزیابی شود.

## اصول پروژه

- استفاده از منابع رایگان؛ هیچ GPU یا Job پولی بدون تأیید صریح اجرا نمی‌شود.
- اندازه‌گیری جداگانهٔ پارامترهای کل، پارامترهای فعال و هزینهٔ محاسباتی مسیر تولید توکن.
- شروع با ممیزی پیکربندی و آزمایش کوچک؛ نه تبدیل یک‌بارهٔ تمام ۲۴ لایه.
- ثبت نتایج قابل‌بازتولید، نسخهٔ کتابخانه‌ها و شناسهٔ دقیق مدل.
- ارزیابی فارسی، ریاضی، منطق، پیروی از دستور، RAM، سرعت و امکان اجرای موبایل.

## شروع ممیزی

1. Notebook با مسیر `notebooks/01_model_audit.ipynb` را در Google Colab یا Kaggle باز کنید.
2. سلول‌های بررسی پیکربندی را اجرا کنید؛ این مرحله برای دانلود کل وزن‌های چندگیگابایتی نیاز ندارد.
3. پیش از بارگذاری کامل مدل، فضای RAM/VRAM و دسترسی رایگان محیط را بررسی کنید.
4. پیش از ساخت مدل کامل، config مقصد و یک نمونهٔ کوچک را از نظر صحت forward و سازگاری runtime اعتبارسنجی کنید.

## هزینه

این مخزن هیچ محاسبهٔ پولی را خودکار اجرا نمی‌کند. سهمیهٔ رایگان Colab/Kaggle ممکن است تغییر کند و GPU رایگان تضمین‌شده نیست.
