# تقطیر واقعی یک FFN از Qwen3.5-2B به MoE top-2

## چه چیزی اجرا می‌شود؟
اسکریپت `scripts/distill_real_qwen_ffn.py` مدل مرجع `Qwen/Qwen3.5-2B` را بارگذاری می‌کند، با forward hook ورودی و خروجی واقعی FFN لایهٔ انتخابی را جمع‌آوری می‌کند و سپس ۸ expert کانال‌شاردشده به‌علاوهٔ router را برای بازسازی خروجی teacher با MSE آموزش می‌دهد. ۱۰٪ توکن‌ها برای ارزیابی جدا نگه داشته می‌شوند. padding در loss حذف می‌شود.

این **تقطیر یک FFN** است، نه تبدیل کل مدل؛ خروجی آن checkpoint آزمایشی است و مستقیم قابل جایگزینی در Qwen نیست. پایین بودن MSE هم به‌تنهایی اثبات حفظ کیفیت زبانی یا استدلال نیست.

## اجرا در محیط رایگان
1. در صورت موجود بودن، یک runtime رایگان Colab باز کنید. این پروژه هیچ GPU یا سرویس پولی فعال نمی‌کند؛ اگر GPU رایگان در دسترس نیست، CPU را انتخاب کنید (کندتر است).
2. نوت‌بوک `notebooks/02_real_activation_ffn_distillation.ipynb` را باز کنید.
3. فایل متنی UTF-8 خود را بارگذاری کنید؛ هر خط یک نمونه باشد. حداقل ۴ نمونه لازم است، اما برای ارزیابی معنادار از چندصد یا چند هزار نمونهٔ متنوع استفاده کنید.
4. سلول‌ها را به ترتیب اجرا کنید. خروجی `eval_mse` خطای FFN روی توکن‌های نگه‌داشته‌شده است.
5. checkpoint آزمایشی `layer0_top2.pt` را ذخیره کنید.

## اجرای محلی
```bash
python -m pip install torch transformers accelerate safetensors
python scripts/distill_real_qwen_ffn.py --text-file data/fa_train.txt --layer 0 --samples 256 --max-length 128 --num-experts 8 --top-k 2 --epochs 3 --batch-size 4 --device auto --output artifacts/layer0_top2.pt
```

## محدودیت‌ها و تفسیر
- بارگذاری مدل مرجع چند گیگابایت RAM می‌خواهد؛ CPU می‌تواند بسیار کند باشد.
- اگر ساختار مدل در نسخهٔ نصب‌شدهٔ Transformers متفاوت باشد، اسکریپت با خطای واضح متوقف می‌شود؛ اجرای آن هنوز باید در محیط واقعی تأیید شود.
- روش کانال‌شاردینگ در آغاز، با جمع همهٔ shardها از نظر ریاضی خروجی dense را بازسازی می‌کند؛ top-2 فقط دو shard را به کار می‌گیرد و به همین دلیل به آموزش نیاز دارد.
- این prototype هنوز quality benchmark، perplexity، سرعت موبایل یا مصرف RAM روی Android را اندازه‌گیری نمی‌کند.
- فایل checkpoint وزن‌های مدل کامل نیست و نباید به‌عنوان مدل آمادهٔ استقرار منتشر شود.
- از داده‌هایی استفاده کنید که مجوز استفاده از آن‌ها را دارید؛ اطلاعات خصوصی را وارد corpus نکنید.
